# New Project Workflow — Skills

- `shape`-style fast discovery
- `grill-me`-style manual discovery
- PRD drafting skill
- PRD slicing skill
- TDD execution skill
- issue triage skill

## Loading rule
Only load the skill needed for the current step. Do not preload the full set on every agent spawn.

## Implementation rule
If a behavior is adopted from a third-party skill, rewrite it locally before use.

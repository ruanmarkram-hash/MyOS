## I. Information Architecture School (01-04)
> Philosophy: "Data is not decoration — it is building material"

### 01. Pentagram - Michael Bierut Style
**Philosophy**: Typography is language; the grid is thought
**Key characteristics**:
- Extremely restrained color (black/white + 1 brand color)
- Modern interpretation of the Swiss grid system
- Typographic hierarchy as the primary visual language
- Strategic use of negative space (60%+ whitespace)

**Prompt DNA**:
```
Pentagram/Michael Bierut style:
- Extreme typographic hierarchy, Helvetica/Univers family
- Swiss grid with precise mathematical spacing
- Black/white + one accent color (#HEX)
- Information architecture as visual structure
- 60%+ whitespace ratio
- Data visualization as primary decoration
```

**Signature work**: Hillary Clinton 2016 campaign identity
**Search keywords**: pentagram hillary logo system

## Prompt Usage Guide

**Combination formula**: `[Style Prompt DNA] + [Scene Template (see scene-templates.md)] + [Specific Content]`

### Core Principle: Describe Mood, Not Layout

The key to AI image generation: short prompts beat long prompts. Describing 3 sentences of mood and content works better than 30 lines of layout detail.

| Kills diversity | Sparks creativity |
|----------------|----------------|
| Specify color ratios (60%/25%/15%) | Describe mood ("warm like Sunday morning") |
| Prescribe layout positions ("title centered, image on right") | Reference a specific aesthetic ("Pentagram editorial feel") |
| Constrain character poses and expressions | Let the AI naturally interpret the style |
| List all visual elements to include | Describe what the audience should feel |

### Good / Bad Examples

**Bad — over-constrained (AI output comes out flat and empty):**
```
Professional presentation slide. Dark background, light text.
Title centered at top. Two columns below. Left column: bullet points.
Right column: bar chart. Colors: navy 60%, white 30%, gold 10%.
Font size: title 36pt, body 18pt. Margins: 40px all sides.
```

**Good — mood-driven (output is varied and textured):**
```
A data visualization that feels like a Bloomberg Businessweek
editorial spread. The key number "28.5%" should dominate the
composition like a headline. Warm cream tones with sharp black
typography. The data tells a story of dramatic channel shift.
```

### Execution Path Selection

Choose based on the "Best Path" column in the quick reference table:
- **AI Gen**: Styles with clear visual elements (06/07/12/13/14/15/16/20) — use Gemini/Midjourney for direct output
- **HTML rendering**: Styles relying on precise typography (01/03/04/10/11/17/18) — code controls data and layout
- **Hybrid**: HTML for structural layout + AI-generated images/backgrounds (02/05/08/09/19)

### Quality Control

1. ❌ Do not write "in the style of Pentagram" directly → ✅ Describe specific design characteristics
2. Text often goes wrong in AI generation → replace text after generating
3. Proportions distort easily → explicitly specify aspect ratio
4. Generate 3-5 variants first, then refine the best one

**Default aesthetic prohibited zones** (user can override per their brand):
- ❌ Cyber neon / dark blue backgrounds (#0D1117)
- ❌ Personal signatures/watermarks on cover images
